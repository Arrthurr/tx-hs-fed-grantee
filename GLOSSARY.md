# Texas Head Start Location Directory

An exploratory, owner-supplied directory of listed locations and project-defined
TXHSA regions. It is not a complete census or an authoritative funding source.

## Language

**Listed location**:
A distinct location record accepted from the directory. Its presence does not
verify its current operation, program type, grantee, or funding.
_Avoid_: Verified program, statewide program total

**TXHSA region**:
One of the project's four county groupings: West, North, East, or South. Each
grouping follows the TDEM-to-TXHSA merge mapping and deliberate county overrides.
_Avoid_: TDEM region, congressional district
